# Classification of Rice Image Dataset Using Deep Learning 

**Dataset:** [Rice Image Dataset] (https://www.kaggle.com/datasets/muratkokludataset/rice-image-dataset) — orijinal sahiplerine aittir.

## Kullanılan Yöntemler
- Custom CNN
- MobileNetV2 Transfer Learning

## Sonuçlar
Model MobileNetV2 yontemi ile macro avg  ve weighted avgde 0.99 lik basari orani yakalamistir. Fine-tuning kismi ile cok cuzi bir gelistirme yapilabilir.
